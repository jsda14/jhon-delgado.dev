- 🏗️ [`specs/02-architecture-design.md`](./specs/02-architecture-design.md) — Diseño de capas, separación de lógica/interfaz y alias de importación.

## ⚡ Instalación y Desarrollo Local

```bash
# Clona el repositorio
git clone [https://github.com/jsda14/jhon-delgado.dev.git](https://github.com/jsda14/jhon-delgado.dev.git)

# Entra al directorio
cd jhon-delgado.dev

# Instala dependencias
npm install

# Inicia el servidor de desarrollo
npm run dev
